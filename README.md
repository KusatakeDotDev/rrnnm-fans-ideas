# rrnnm.fans（非公式）への提案窓口

[rrnnm.fans](https://rrnnm.fans) は、個人で運営している非公式のファンサイトです。このリポジトリでは、サイトへのアイデアや、直してほしいところを受け付けております。

## 送り方

[Discussions](https://github.com/KusatakeDotDev/rrnnm-fans-ideas/discussions) で、カテゴリを選んで投稿してください。

| カテゴリ | 送っていただきたいこと |
| --- | --- |
| 💡 アイデア提案 | こんなページ・機能があったらうれしい、というもの |
| 🔧 直してほしいところ | 動かない・見づらい・表示がおかしい など。小さなことでもどうぞ |
| 📣 おしらせ | 制作者からのお知らせです（投稿はできません） |

ほかの方の投稿と同じ内容なら、新しく立てずに 👍 を付けていただけると助かります。

## こう書いていただけると助かります

- どのページの、どこのことか
- どうなっていたらうれしいか

「ここが気になる」より「こうなっていたらうれしい」のほうが、取り入れやすくなります。

## DM でお送りいただきたいこと

削除・訂正のご依頼、権利やプライバシーに関わることは、公開の場に残らないよう、制作者の X アカウント [@ekatas93](https://x.com/ekatas93) へ DM でお願いいたします。

ご本人・関係者からのお申し出には、理由を問わず応じます。

## いただいたご提案について

状態をラベルでお知らせしております。

| ラベル | 意味 |
| --- | --- |
| 考え中 | 検討しています |
| やる | 取り入れることにしました |
| 反映済み | サイトに反映しました |
| 見送り | 今回は見送ります |

すべてのご提案を取り入れられるとは限りません。あらかじめご了承ください。
